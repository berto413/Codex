# Ruta 242699: descargar y compartir

El archivo **`Ruta242699.html`** contiene la aplicación, las lecciones, las preguntas, el manual y los documentos incluidos. Para usarlo no hacen falta instalaciones ni una cuenta.

## Descargar desde GitHub

1. Abre `Ruta242699.html` en la lista de archivos del repositorio.
2. Pulsa **Download raw file** (icono de descarga) para guardar el archivo en tu computador. Si el navegador muestra el código en una pestaña, usa **Guardar como** y conserva el nombre `Ruta242699.html`.
3. También puedes elegir **Code → Download ZIP**, extraer el ZIP y buscar `Ruta242699.html`.

## Entregar a otra persona

Envía **`Ruta242699.html` como documento adjunto** por WhatsApp o correo. La otra persona debe guardarlo en su computador y abrirlo con Chrome o Edge. Luego puede pulsar **Continuar mi sesión**.

El manual y los documentos se descargan desde la sección **Fuentes** de la aplicación. Para estudiar sin conexión basta el archivo HTML; los enlaces a sitios oficiales sí necesitan Internet.

Cada persona conserva su avance en el navegador de su propio equipo. Para respaldarlo debe usar **Exportar progreso** dentro de la aplicación. El archivo entregado no contiene el progreso del remitente.

La aplicación es una preparación independiente y parcial: incluye 13 lecciones y 85 preguntas revisadas. No es una aplicación oficial ni una réplica del examen. La fecha de examen indicada procede de la solicitud y no está confirmada oficialmente.
